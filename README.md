- Work experience

- Education
- Contact links
- Downloadable CV

## Run locally
Open `index.html` in a browser, or run a lightweight local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

### Option A — Personal site (recommended)
1. Create a new GitHub repository named exactly `missBeya.github.io`.
2. Copy all files from this folder into that repository.
3. Push to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Save.

Your site will appear at:
`https://missbeya.github.io`

### Option B — Project site
You can also create a repository such as `portfolio` and enable GitHub Pages from the `main` branch.
